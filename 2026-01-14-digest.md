## Top 3 Updates

1. **[Anthropic debuts Cowork — Claude as a file-based agent for everyday workflows](https://cc554gl0.r.us-east-2.awstrack.me/L0/https:%2F%2Fapp.alphasignal.ai%2Fc%3Fuid=aZGOCm7tHMvJ9f1l%26cid=7139cec86f731805%26lid=YVlmvQhzbtfR7IOn/1/010f019bb86e9ddc-bdef12e3-d0ef-49ae-b1ad-1f1dffb14420-000000/c0WNEuo0gYl8Wv6Dbsrb6FsDDXk=245)**  
   Source: AlphaSignal  
   Summary: Anthropic’s Cowork applies the Claude agent model to local folders and documents — it can read, edit, create, rename, and delete files inside an approved folder and execute multi-step tasks autonomously. This reduces the friction of copy-paste and repeated prompting for multi-file knowledge work and brings agent-style automation to non-developer users (research preview for Claude Max on macOS).

2. **[DeepSeek introduces Engram — a constant-time N‑gram memory module for Transformers](https://cc554gl0.r.us-east-2.awstrack.me/L0/https:%2F%2Fapp.alphasignal.ai%2Fc%3Fuid=aZGOCm7tHMvJ9f1l%26cid=7139cec86f731805%26lid=1E0ntCxftCdlBSEK5/2/010f019bb86e9ddc-bdef12e3-d0ef-49ae-b1ad-1f1dffb14420-000000/Wr6wttdsN7ynPWuIyUxZkkNN240=245)**  
   Source: AlphaSignal (paper highlight)  
   Summary: Engram embeds a hashed N‑gram lookup in early/mid Transformer layers so models fetch repeating token patterns in O(1) instead of relearning them each forward pass. Results show material gains in factual recall and reasoning (examples: +3.4 MMLU, +5.0 BBH), and the released code shows how to fuse memory lookups with standard Transformer blocks.  
   > Engram can raise long-context retrieval (Multi-Query NIAH) from 84.2 → 97.0 and meaningfully improves math, code, and reasoning benchmarks.

3. **[OpenAI acquires Torch to add persistent medical memory to ChatGPT Health](https://cc554gl0.r.us-east-2.awstrack.me/L0/https:%2F%2Fapp.alphasignal.ai%2Fc%3Fuid=aZGOCm7tHMvJ9f1l%26cid=7139cec86f731805%26lid=1yIcHyreEwIsPifWJ/2/010f019bb86e9ddc-bdef12e3-d0ef-49ae-b1ad-1f1dffb14420-000000/eVAWN6Od3B%5F6hnXpCq9yW7w6Tks=245)**  
   Source: AlphaSignal  
   Summary: OpenAI’s Torch acquisition brings a “unified medical memory” capability — consolidating records from hospitals, labs, wearables, and consumer apps into a longitudinal timeline ChatGPT Health can query. This moves health Q&A from stateless snapshots toward history-aware reasoning, with clear implications for clinical continuity and patient context.
