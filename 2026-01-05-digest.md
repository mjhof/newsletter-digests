## Top 3 Updates 🚀

• **[Netflix scales generative recommender to 1B parameters (10‑min read)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Flinks.tldrnewsletter.com%2FeZ3e7o/1/0100019b8de20018-f4c6f3ed-4162-4e32-851a-e4d4c4e9bf7d-000000/ITJE4UI%5F28yMtuOHhnbdjlS7zWcIb2fOUpzFB4p69mw=438)** — TLDR Data  
  Netflix reports a jump from 1M → 1B parameter generative recommenders, processing ~2 trillion tokens and handling catalogs up to 40× larger than GPT‑3’s. They combined efficiency techniques (sampled softmax, projected heads, multimodal towers) and a multi‑token objective to improve cold‑start and low‑latency serving. This shows generative recommenders are now being engineered for web‑scale production constraints — a blueprint for personalization at massive catalogue scale.

• **[OpenAI ships GPT‑5.2‑Codex for long coding sessions (report)](https://cc554gl0.r.us-east-2.awstrack.me/L0/https:%2F%2Fapp.alphasignal.ai%2Fc%3Fuid=kJ9PeNpvkGIH45M5%26cid=910cbd9eb56f99ec%26lid=mRrp2BttIKQDLEl9/1/010f019b37b92032-139cf43f-b221-4740-9209-04b39d520d41-000000/ma-2FV%5Fsj2yW5v3lXtJYRZWasug=242)** — AlphaSignal  
  GPT‑5.2‑Codex focuses on preserving task state across long, multi‑step engineering workflows via native context compaction, improved tool calling and terminal control, and vision inputs for screenshots. Benchmarks show incremental gains (SWE‑Bench Pro 56.4%, Terminal‑Bench 64.0%), but the real win is reliability across extended developer sessions — a key step toward models that actually drive sustained software work.

• **[Anthropic releases Bloom to cut model evaluation from weeks to days](https://cc554gl0.r.us-east-2.awstrack.me/L0/https:%2F%2Fapp.alphasignal.ai%2Fc%3Fuid=kJ9PeNpvkGIH45M5%26cid=112c11be965cb5d9%26lid=V4rRQJvf8PEtAg6/1/010f019b4740dcf9-50ee9ffb-75ed-44ff-ada0-09816b44ef0a-000000/NxxtyP5eFEyE02jzM7WP-gki5F8=242)** — AlphaSignal / Anthropic  
  Bloom automates behavioral evaluations: define a behavior seed, Bloom generates diverse scenarios, runs parallel multi‑turn rollouts, and scores outcomes — enabling reproducible behavioral tests in days rather than weeks. For safety and governance teams this reduces test brittleness and speeds iteration across frontier models.

> Notable stats: Netflix processed ~2 trillion tokens and handled catalogs 40× GPT‑3 size; GPT‑5.2‑Codex SWE‑Bench Pro ≈ **56.4%**; Google’s FunctionGemma pushes function‑calling accuracy from **58% → 85%** on-device.
