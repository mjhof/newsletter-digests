• **[Anthropic adds Tool Search to Claude Code to avoid token bloat from large MCP toolsets](https://app.alphasignal.ai/c?uid=aZGOCm7tHMvJ9f1l&cid=5ec45b516be509ff&lid=ZEXNQooDSO78yfzk)**  
  Source: AlphaSignal  
  Summary: When tool descriptions start to consume >10% of context, **Claude Code** now switches from preloading all MCP tool schemas to search‑loading only the relevant ones. This removes a fixed token overhead (teams were burning tens of thousands of tokens on tool descriptions at scale) and makes MCPs practical at larger sizes.

> “Teams run 7+ MCP servers and burn 67k+ tokens on tool descriptions alone.” — key motivation behind Anthropic’s Tool Search.
