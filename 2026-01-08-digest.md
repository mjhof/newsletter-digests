• **[Stanford SleepFM predicts 130 diseases from one night of sleep data](https://cc554gl0.r.us-east-2.awstrack.me/L0/https:%2F%2Fapp.alphasignal.ai%2Fc%3Fuid=aZGOCm7tHMvJ9f1l%26cid=17be09433fc69b47%26lid=GPHIMwkOmlVko7Fy/2/010f019b998b46ce-1c1a602c-ade1-4769-a1b7-84658b300394-000000/ZZPE43stZAqGYJCb9uwMfWqpsuE=245)

  Summary: Stanford released SleepFM (open-source), a multimodal model trained on 585K hours of polysomnography linked to longitudinal health records. • **[NVIDIA debuts Nemotron Speech ASR — cache-aware streaming for low-latency voice agents](https://cc554gl0.r.us-east-2.awstrack.me/L0/https:%2F%2Fapp.alphasignal.ai%2Fc%3Fuid=aZGOCm7tHMvJ9f1l%26cid=17be09433fc69b47%26lid=gGnPRoOzkM2vIDmA/2/010f019b998b46ce-1c1a602c-ade1-4769-a1b7-84658b300394-000000/RcLuNVrPdWZtPp7uowejtmM9-3I=245)  
  Source: **AlphaSignal**  
  Summary: NVIDIA’s open ASR, Nemotron, uses cache-aware streaming to avoid reprocessing overlapping audio frames — significantly reducing GPU memory growth and preserving low latency under load. On an H100 it reports ~24 ms median time-to-final transcription and supports ~560 concurrent streams, making it suited for real-time voice agents at scale.  
  > “24 ms median time-to-final transcription and stable support for 560 concurrent streams on an H100.”

• **[Cursor introduces dynamic context discovery to cut agent token usage (~47%)](https://tracking.tldrnewsletter.com/CL0/https:%2F%2Fcursor.com%2Fblog%2Fdynamic-context-discovery%3Futm%5Fsource=tldrai/1/0100019b98e5dce1-e9343087-7bcb-42e9-b42b-8a3962d473af-000000/Kv2GTgwvxdmDQL6KrQ1Huu4kuw9ttruo-37bgKg60%5Fs=439)  
  Source: **AlphaSignal; TLDR AI**  
  Summary: Cursor shifts from huge static prompts to file-backed, on-demand context loading: tool outputs, logs, and history are written to files and only fetched when needed. In internal tests this reduced total agent token usage by ~46.9% without harming task quality — a practical step for making long-running agents cheaper and more reliable.
